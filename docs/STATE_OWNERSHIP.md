# 编辑状态归属

这份边界说明用于后续拆分大组件时保持行为一致。每次拆分先为相应行为建立回归，再迁移状态。

| 状态 | 唯一持有者 | 对外边界 |
| --- | --- | --- |
| 当前项目、词条、筛选和提交队列 | `useEditor` | `EditorWorkspace` 通过公开方法选择、编辑和提交；全文编辑器通过 `api` 保存后刷新相同项目的可见列表。 |
| 远程列表请求取消 | `ListRequestCoordinator` | `useEditor` 为每个 `strings` 请求分配 ID，筛选变化时取消旧请求；响应仍由调用方序号决定是否使用。 |
| 主编辑器草稿 | `useEditor` 和本机 Rust 草稿仓库 | 草稿按账号／项目／词条保存；离开词条、窗口关闭和远端提交前等待落盘。 |
| 全文编辑器临时行与草稿写队列 | `ProjectTextEditor` | 行有独立的翻译、术语、保存状态；关闭前等待所有写入。 |
| 翻译请求、当前目标上下文和辅助面板生命周期 | `AuxPanel` | 每次翻译使用目标词条快照；`useEditor` 提供按目标词条获取的术语和建议。 |
| 窗口、凭据、代理及本地服务进程 | `electron/main.cjs` | 预加载桥接限定浏览器可调用的操作；本地服务负责 ParaTranz 请求及草稿持久化。 |

后续可在不改变这些边界的前提下继续拆分 `useEditor` 的提交队列、`AuxPanel` 的翻译请求构造，以及 Electron 的设置存储。当前对这些路径的行为回归由 Electron、Rust、逻辑与浏览器测试覆盖。
